# Data Science & AI Projects

This repository contains my Data Science and Artificial Intelligence projects developed as part of my learning and practical work.

## Projects

### 1. Enterprise Server Failure Prediction

A machine learning project that predicts whether an enterprise server may fail within the next 24 hours.

**Technologies:**
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Logistic Regression
- Random Forest

**Features used:**
- Memory Usage
- Disk I/O
- Network Latency
- Error Rate
- Application Crashes
- Maintenance History
- Server Type

**Model Result:**
- Accuracy: ~72%
- Prediction time: < 5 seconds

---

### 2. Intelligent IT Ticket Auto-Resolution System

A machine learning and NLP project that automatically classifies IT support tickets and suggests suitable solutions.

**Technologies:**
- Python
- Pandas
- NumPy
- Scikit-learn
- TF-IDF
- Logistic Regression
- NLP

**Ticket Categories:**
- Network
- Software
- Hardware
- Account Access
- Email
- Security
- Database
- Printer

**Model Result:**
- Accuracy: 100% on the synthetic test dataset
- Local prediction time: ~0.002 seconds

The system also uses confidence scores and can escalate low-confidence tickets to the IT support team.

The reported results should not be considered production performance. Real-world deployment would require testing on actual company data.
